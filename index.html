How it works

  1. Request: click Request on a tool (or New request) and submit the GitHub form.
  2. Approve: an approver comments /approve or /reject <reason> on the request.
  3. Issue: once the licence is handed over, the approver comments /issue.
  4. Return: when it comes back, the approver comments /return.

Everyone involved gets GitHub notifications at each step. Approvers are listed in catalogue/approvers.json; tools are edited in catalogue/tools.json.
